EL BATLLE

Un poble. Cent persones. Cap llei.

Toca una cabana per veure quina família hi viu i quants dies de menjar li queden.

    DESIGUALTAT · ÍNDEX DE GINI

    — · 0 vol dir que totes les cases tenen el mateix; 1, que una sola casa ho té tot. Compta el menjar, els materials, les ovelles i les cases de cada família. Les marques numerades són les lleis, i les línies vermelles amb bandera, les revolucions.

    Part de tota la riquesa del poble que té cada 10% de cases: a l'esquerra, el 10% més pobre; a la dreta, el 10% més ric. La línia discontínua és el 10% que tindria cada grup si tot estigués repartit igual.
